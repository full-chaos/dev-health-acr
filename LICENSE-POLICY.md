# License policy for SVS

This repository is private during the smallest viable slice (SVS). No public source license is granted at this stage.

The intended future posture is:

- The MCP sidecar may be published under Apache License 2.0 once the API, entitlement, update, and distribution model is stable.
- The hosted ACR API remains a purchased Dev Health capability.
- Production entitlement enforcement occurs server-side.
- The client binary must not depend on obscurity or hidden license-validation code as a security boundary.

This document is an engineering policy note, not a commercial license agreement.
